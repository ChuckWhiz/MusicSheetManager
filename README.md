MusicSheetManager

MusicSheetManager is a small console application I made to help me manage my music sheet folder. Currently, it can do these things:

Print all files in various orders
Search for a file and then display it's filesystem metadata (e.g. filename, file size, last modified, etc. etc.)

There's still a lot more features I'd like to add (like seeing the last time a music sheet was used) and eventually, I'd like to make a GUI for it.

Feel free to download the source code and use it in your own projects if you like! (Just please credit me if you make your project public :))
